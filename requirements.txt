# ============================================
# Data Handler — Requirements
# ============================================
#
# Split into requirements/*.txt so the Docker build can install each group as
# its own layer. Docker pulls layers in parallel (3 at a time by default) but
# cannot parallelise *within* a layer — one 1 GB layer downloads on a single
# connection. Splitting turned the image pull from one serial stream into
# several concurrent ones.
#
#   requirements/core.txt    web, DB, queue, utils      (~120 MB)
#   requirements/data.txt    numpy/pandas/scipy/sklearn (~220 MB)
#   requirements/extras.txt  qdrant, litellm, exports   (~110 MB)
#   requirements/ml.txt      transformers + s-t         (~150 MB, needs torch)
#   requirements/dev.txt     pytest, ruff, mypy         (not shipped in images)
#
# This aggregate keeps `pip install -r requirements.txt` behaving as before —
# a full install including the ML stack.
#
# torch is intentionally absent: it needs a custom index URL. Install it with
#   CPU:  pip install torch --index-url https://download.pytorch.org/whl/cpu
#   XPU:  make install-ml
# The Docker build does this for you (see infrastructure/Dockerfile).

-r requirements/core.txt
-r requirements/data.txt
-r requirements/extras.txt
-r requirements/ml.txt
